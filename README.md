# Calculadora - Modern Tech Design 🧮

Uma calculadora moderna e elegante com design em gradiente azul e preto. Totalmente funcional com interface intuitiva e responsiva.

## ✨ Características

- **Design Moderno** - Gradiente azul e preto com efeito glassmorphism
- **Interface Intuitiva** - Botões com animações suaves
- **Totalmente Responsiva** - Funciona em todos os dispositivos
- **Suporte a Teclado** - Use seu teclado para fazer contas
- **Operações Completas** - Adição, subtração, multiplicação, divisão e porcentagem

## 🎨 Tecnologias Utilizadas

- HTML5
- CSS3 (Gradientes, Glassmorphism, Animações)
- JavaScript Vanilla
- Design Responsivo

## 🚀 Como Usar

1. Acesse o site
2. Digite os números usando os botões ou teclado
3. Selecione a operação desejada (+, -, ×, ÷, %)
4. Pressione "=" para obter o resultado

## ⌨️ Atalhos de Teclado

- `0-9` - Números
- `.` - Ponto decimal
- `+` `-` `*` `/` - Operadores
- `Enter` ou `=` - Calcular
- `Backspace` - Deletar último dígito
- `Esc` - Limpar tudo

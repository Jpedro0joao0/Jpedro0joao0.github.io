## 🚀 Como Usar

### **Conversor de Moedas**
1. Clique na aba "💱 Conversor"
2. Digite o valor na caixa "De"
3. Selecione a moeda de origem
4. Selecione a moeda de destino
5. O resultado aparece automaticamente
6. Clique em "⇅" para trocar as moedas
7. Clique em "📋 Copiar Resultado" para copiar o valor

### **Calculadora**
1. Clique na aba "🧮 Calculadora"
2. Digite números usando os botões ou teclado
3. Selecione operações: +, −, ×, ÷, %
4. Pressione "=" para calcular
5. Use "AC" para limpar tudo
6. Use "⌫" para deletar o último dígito

## ⌨️ Atalhos de Teclado (Calculadora)

| Atalho | Função |
|--------|--------|
| `0-9` | Inserir números |
| `.` | Ponto decimal |
| `+` `-` `*` `/` | Operadores |
| `Enter` ou `=` | Calcular resultado |
| `Backspace` | Deletar último dígito |
| `Esc` | Limpar tudo (AC) |

## 🔧 Como Personalizar

### Alterar Cores
Edite as cores em `styles.css`:
```css
/* Linha ~38 */
background: linear-gradient(135deg, #a855f7 0%, #d946ef 50%, #a855f7 100%);
```

### Adicionar Mais Moedas
Edite `script.js` e `index.html`:
```javascript
// script.js - Adicione a taxa
const exchangeRates = {
    'BRL': 5.15  // Nova moeda
};

// index.html - Adicione a opção
<option value="BRL">BRL (Real Brasileiro)</option>
```
